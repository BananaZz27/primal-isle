# ขั้นที่ 6ข — PWA + ขึ้นออนไลน์ Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** เพิ่มเกมเป็นไอคอนบนหน้าจอโฮมได้ และเตรียมทุกอย่างให้ขึ้นออนไลน์ได้ด้วยการกดไม่กี่ปุ่มของโบ๊ท
**Architecture:** client = เว็บนิ่งบน GitHub Pages (build ผ่าน Actions) · server = Docker image เดียวใช้ได้ทั้ง Render และ Oracle · คู่มือภาษาไทยใน `docs/DEPLOY.md`
**Tech Stack:** vite-plugin-pwa (Workbox), GitHub Actions (deploy-pages), Docker (node:22-slim), Render blueprint
**Spec:** `docs/superpowers/specs/2026-11-22-m6b-online-design.md`

## Global Constraints
- ห้ามมีรหัสลับ/token ใดๆ ใน repo — ค่าเซิร์ฟเวอร์อยู่ในตัวแปร repo `SERVER_URL` (ไม่ลับ)
- เซิร์ฟเวอร์จริง: `NODE_ENV=production` → ไม่มี `/monitor` / playground
- service worker แบบ `autoUpdate` และไม่แคชการเชื่อมต่อเซิร์ฟเวอร์
- คู่มือเป็นภาษาไทย อธิบายศัพท์เทคนิค

## Review Focus
1. **เกมเวอร์ชันใหม่ขึ้นแล้วแต่มือถือยังเปิดเวอร์ชันเก่า** → service worker อัปเดตเอง
2. **หน้าเว็บบน https ต่อเซิร์ฟเวอร์ ws:// ไม่ได้ (mixed content)** → ใช้ wss จาก `SERVER_URL`
3. **workflow Pages รันก่อนตั้งค่า → กากบาทแดงทุก push** → รันเฉพาะเมื่อตั้ง `SERVER_URL` แล้ว หรือกดเอง
4. **Render รีสตาร์ท → เซฟหาย** → คู่มือบอกชัด + Oracle เก็บถาวร
5. **`/monitor` หลุดบนเซิร์ฟเวอร์จริง** → เทสต์
