# ขั้นที่ 3 เอาชีวิตรอด — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** เก็บทรัพยากร (ไม้/หิน/ผลไม้/เส้นใย) ที่งอกใหม่ได้, ต้นไม้และหินชนได้, กระเป๋า, ค่าเลือด/หิว/น้ำ, กิน/ดื่ม, สลบแล้วฟื้น

**Architecture:** กติกาทั้งหมดเป็น pure function ใน `shared` (ข้อมูลสมดุลใน JSON) · เซิร์ฟเวอร์ถือสถานะทรัพยากรที่ถูกแตะ (`nodes`) + ค่าผู้เล่น + กระเป๋า และรับข้อความ `gather/eat/drink` · client อ่าน state มาวาด/ทำนายการชน และส่งข้อความเมื่อกดโต้ตอบ

**Tech Stack:** เดิม — ไม่เพิ่ม dependency

**Spec:** `docs/superpowers/specs/2026-11-21-m3-survival-design.md` (+ สเปกหลัก `2026-11-21-primal-isle-design.md`)

## Global Constraints
- ตัวเลขสมดุลทั้งหมดอ่านจาก `shared/src/data/balance.json` เท่านั้น
- ระยะเก็บ 24px (กลางตัว → กลางช่อง), คูลดาวน์ตี 350ms, stack สูงสุด 99, ค่าสถานะ 0–100
- id ทรัพยากร = index ใน `generateDecor(map)`; ดอกไม้ไม่ใช่ทรัพยากร
- เซิร์ฟเวอร์ปฏิเสธคำขอที่ผิดเงียบๆ (ไม่ throw, ไม่ตัดการเชื่อมต่อ)
- `stepPlayer` ต้องยังเป็น pure function และเทสต์เดิมต้องผ่าน (พารามิเตอร์ `solid` เป็น optional)
- ข้อความที่ผู้เล่นเห็นเป็นภาษาไทย; ห้าม innerHTML

## Review Focus
1. **ต้นไม้งอกทับผู้เล่น** → ผู้เล่นติดในของแข็ง เดินไม่ได้ — ต้องเลื่อนการงอกออกไป (เทสต์ห้อง: "does not regrow under a player", Task 2)
2. **กด gather รัว / id ปลอม / ไกลเกิน / ทรัพยากรหมดแล้ว** → ไม่ได้ของฟรี (เทสต์ห้อง 4 กรณี, Task 2)
3. **ค่าหิว/น้ำ/เลือดหลุดช่วง 0–100 หรือเป็น NaN** หลัง dt ยาวๆ (เน็ตสะดุด/แท็บพัก) → clamp เสมอ (เทสต์ `tickStats` dt=3600, Task 1)
4. **ฟื้นแล้วเกิดในต้นไม้/หิน** → จุดเกิดไม่มีของแข็ง (เทสต์ decor เดิม + "respawn point is not solid", Task 1)
5. **มือถือ: กดปุ่มโต้ตอบแล้วนิ้วอีกข้างที่ลาก joystick หลุด** → ปุ่มรับ pointer แยก ไม่ขโมย joystick (ตรวจใน headless touch, Task 5)

### Task 1: กติกาใน shared (ข้อมูลสมดุล, ทรัพยากร, ค่าสถานะ, การชน)
**Files:** Create `shared/src/data/balance.json`, `shared/src/rules/resources.ts`, `shared/src/rules/survival.ts`; Modify `shared/src/world/decor.ts` (เพิ่ม `DecorKind.Bush = 4`), `shared/src/movement/step.ts`, `shared/src/index.ts`, `shared/tsconfig.json`; Test `shared/test/resources.test.ts`, `shared/test/survival.test.ts`, `shared/test/movement.test.ts`
**Produces:**
- `BALANCE` (typed import ของ JSON) และ `type ItemId = "wood" | "stone" | "berry" | "fiber"`
- `nodeDef(kind: DecorKind): { item: ItemId; hits: number; regrowSec: number; solid: boolean } | null` (Flower → null)
- `inReach(px: number, py: number, tx: number, ty: number): boolean` (ระยะ ≤ `BALANCE.gatherReach`)
- `touchesWater(map, px, py): boolean` — มีช่องน้ำในระยะเก็บรอบตัว
- `solidFromNodes(map, decor, isDepleted: (id: number) => boolean): (tx, ty) => boolean`
- `interface Stats { health: number; hunger: number; thirst: number }`, `freshStats(): Stats`, `tickStats(s: Stats, dt: number): { died: boolean }` (แก้ค่าในตัว, clamp 0–100)
- `stepPlayer(entity, input, dt, map, solid?)` — ช่องที่ `solid` = true เดินไม่ได้
- generateDecor: บนหญ้าแบ่ง flower 35% / tuft 30% / pebble 20% / bush 15%
**Tests (เขียนก่อน):** nodeDef ตามตารางในสเปก · inReach ที่ 24 ได้/25 ไม่ได้ · tickStats: หิวลดตามเวลา, หิว 0 → เลือดลด, ฟื้นเมื่ออิ่ม, dt 3600 ไม่หลุดช่วง/NaN, died เมื่อเลือดถึง 0 · stepPlayer ชนช่อง solid · solidFromNodes: ต้นไม้/หินเป็นของแข็ง, หมดแล้วไม่แข็ง, พุ่มไม้ไม่แข็ง · จุดเกิดทั้ง 8 ไม่ใช่ของแข็ง (50 seed)
**Commit:** `feat(shared): survival rules, resource nodes and solid collision`
