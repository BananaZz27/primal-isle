# ขั้นที่ 7 — โลกมีชีวิต Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** กลางวัน/กลางคืน, กล่องเสบียงจากโลกปัจจุบัน, กล่องเก็บของใช้ร่วมกัน + เก็บกวาดบั๊กเล็กจากรีวิวก่อนหน้า
**Architecture:** กติกา/ตัวเลข/สุ่มของ อยู่ใน `shared/` (pure) · เซิร์ฟเวอร์ซิงก์ `clock`, `crates`, `chests` · client คำนวณความมืดเองจาก `clock`
**Tech Stack:** TypeScript, Colyseus schema, Phaser 4.2 (Graphics overlay + additive glow), Vitest
**Spec:** `docs/superpowers/specs/2026-11-22-m7-living-design.md`

## Global Constraints
- ตัวเลขทั้งหมดใน `balance.json` · ข้อความจาก client ตรวจทุกช่อง · UI ใช้ `textContent`
- ไฟล์บันทึก version 3 อ่าน version 1–2 ได้ · ห้ามมี token ใน state ที่ซิงก์
- ไม่ใช้ Phaser Lights (มือถือ)

## Review Focus
1. **สองคนเปิดกล่องเสบียง/หยิบของชิ้นสุดท้ายในกล่องเก็บของพร้อมกัน** → ได้คนเดียว ของไม่งอก
2. **ย้ายของเข้ากล่องตอนกล่องหรือกระเป๋าเต็ม 99 / จำนวนติดลบ/ทศนิยม/ชนิดมั่ว** → ไม่เสียของ ไม่งอก
3. **รื้อกล่องที่มีของ** → รื้อไม่ได้ (ของไม่หาย)
4. **กล่องเสบียงตกทับกำแพง/น้ำ/ใกล้คน** → ไม่เกิด
5. **รีสตาร์ทแล้วเวลา/ของในกล่อง/กล่องเสบียงหาย** → กลับมาครบ

Produces: `CONSUMABLES`, `isConsumable`, `darkness(clockSec) → 0..1`, `isNight(clockSec)`, `rollLoot(rand) → Partial<Record<ItemId,number>>` (2–3 ชนิด), `crateSpawnOk(map, solid, tx, ty, players)`, `chestMoveCheck(...)`, `DinoView.aggroMul`, brain home timeout
Tests: ความมืด 0 กลางวัน 1 กลางคืน ไล่ระดับช่วง dusk · rollLoot ได้ 2–3 ชนิด จำนวนในช่วง เสมอ · consumables ครบ · แร็พเตอร์กลางคืนไล่ 144px · กลับบ้านไม่ได้ 8 วิ → เลิกดื้อ ตั้งบ้านใหม่ · chestMoveCheck (เต็ม/ติดลบ/ทศนิยม/ชนิดมั่ว/เกิน 12 ชนิด)
