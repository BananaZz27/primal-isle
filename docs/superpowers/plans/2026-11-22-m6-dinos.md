# ขั้นที่ 6ก — ไดโนเสาร์ Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** ไดโน 4 ชนิดเดินเองบนเกาะ ล่าได้เนื้อ ย่างเนื้อ ไดโนกินเนื้อทำร้ายคน เทมได้ 2 ชนิด บันทึกลงไฟล์โลก
**Architecture:** กติกาและสมอง AI เป็นฟังก์ชัน pure ใน `shared/` (ทดสอบได้โดยไม่มีห้อง) · `server/` มี `DinoSystem` เป็นผู้ตัดสิน · `client/` วาดด้วย lerp ของ Predict (ไม่ทำนาย)
**Tech Stack:** TypeScript, Colyseus 0.18 schema, Phaser 4.2, Vitest
**Spec:** `docs/superpowers/specs/2026-11-22-m6-dinos-design.md`

## Global Constraints
- ตัวเลขทุกตัวใน `shared/src/data/balance.json` (ห้ามฝังในโค้ด)
- token ของเจ้าของห้ามอยู่ใน state ที่ซิงก์ — `Dino.owner` = ชื่อที่แสดงเท่านั้น
- ข้อความจาก client ตรวจทุกช่อง (id มั่ว/ไกล/ถี่ = เมินเงียบ)
- UI ใช้ `textContent` เท่านั้น · ภาษาไทยในหน้าจอ
- ไฟล์บันทึก version 2 ต้องอ่านไฟล์ version 1 ได้

## Review Focus
1. **ไดโนเดินทะลุกำแพง/ต้นไม้/ลงน้ำ หรือติดค้างในของแข็งที่งอกทับ** → ชนเหมือนคน ไม่เกิด/งอกทับตัว
2. **แร็พเตอร์ดักจุดเกิด** → จุดเกิดไดโนห่างจุดเกิดคน ≥ 16 ช่อง + สายจูงบ้าน 160px
3. **ป้อน/ตีตัวที่เทมแล้วของคนอื่น, เทมเกิน 3, ป้อนจากไกล** → ไม่ได้
4. **ไดโนที่เทมหายหลังรีสตาร์ท / เจ้าของ (token) หลุดไปใน state** → กลับมาครบ token ไม่ซิงก์
5. **ฆ่าไดโนตอนกระเป๋าเนื้อเต็ม 99 / ตีพร้อมกันสองคน** → ไม่เกิน 99, ตายครั้งเดียว ได้เนื้อครั้งเดียว
