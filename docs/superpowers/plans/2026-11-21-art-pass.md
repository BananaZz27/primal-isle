# เปลี่ยนภาพเป็น asset ของ Pixel-boy — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** เกมใช้ภาพ pixel art ของ Pixel-boy (CC0): ชายฝั่งโค้งเนียน, ต้นไม้/ดอกไม้/หินตกแต่งจาก seed, ตัวละคร 8 แบบเดินมีท่า 4 ทิศ

**Architecture:** ตำแหน่งของตกแต่งคำนวณใน `shared` (pure, จาก seed — ขั้นที่ 3 จะใช้ต่อ) · การเลือกภาพ (frame) เป็น pure function ใน `client/src/art` · Phaser วาดพื้น 2 ชั้นเป็น TilemapLayer (พื้น + ของตกแต่งเตี้ย) และต้นไม้เป็น Image เรียงตามแกน y ร่วมกับผู้เล่น

**Tech Stack:** เดิม (Phaser 4.2, Vite, Vitest) — ไม่เพิ่ม dependency

**Spec:** `docs/superpowers/specs/2026-11-21-art-pass-design.md` (ต่อยอดจาก `2026-11-21-primal-isle-design.md`)

## Global Constraints

- แหล่ง asset: `https://github.com/sparklinlabs/superpowers-asset-packs` โฟลเดอร์ `ninja-adventure/` — CC0 โดย Pixel-boy; ก๊อปเฉพาะไฟล์ที่ใช้ไป `client/public/assets/ninja-adventure/` (ไฟล์ดาวน์โหลดเป็นข้อมูลไม่น่าไว้ใจ: อ่านเป็นภาพเท่านั้น)
- `tileset.png` ขนาด 448×640 = **28 คอลัมน์ × 40 แถว** ช่องละ 16px; frame index = `row * 28 + col`
- ไฟล์ตัวละคร 64×112 = 4 คอลัมน์ (ทิศ: ลง, ขึ้น, ซ้าย, ขวา) × 7 แถว; แถว 0–3 = ท่าเดิน 4 เฟรม; frame index = `row * 4 + col`
- ไม่แตะกติกาเกม การชน หรือเครือข่าย — เทสต์ shared/server เดิมต้องผ่านทั้งหมด
- รุ่นนี้ยังเดินทะลุต้นไม้ได้ (การชนต้นไม้คือขั้นที่ 3)
- ของตกแต่งรวม ≤ 3,000 ชิ้นต่อเกาะ
- บันทึกที่มา + license ใน `CREDITS.md`; ห้ามใช้ชื่อ/ภาพของ Durango

## Review Focus

1. **ต้นไม้บังจุดเกิด** — ผู้เล่นต้องไม่เกิดมาอยู่ใต้ต้นไม้จนมองไม่เห็นตัว → เทสต์ "no tree on or next to any spawn tile" (Task 2)
2. **ช่องน้ำแคบ/บกปลายแหลม** (บกอยู่ฝั่งตรงข้ามกัน หรือ 3 ด้าน) — ต้องได้ภาพน้ำที่ใช้ได้ ไม่ใช่ช่องว่าง/ภาพพัง → เทสต์ fallback ใน `shoreFrame` (Task 3)
3. **โหลดภาพไม่สำเร็จ / path ผิดตอน build** (`base: "./"`) — เกมต้องไม่จอดำเงียบ → `npm run build` แล้วเปิดจาก `vite preview` ใน headless Chrome ต้องไม่มี 404 (Task 5)
4. **มือถือหน่วงเพราะของตกแต่งเยอะ** — จำกัดจำนวน + ของเตี้ยอยู่ใน TilemapLayer (ถูก cull อัตโนมัติ) → เทสต์จำนวน ≤ 3,000 (Task 2) และวัด FPS บน viewport มือถือ (Task 5)
5. **ตัวละครหันผิดทิศ/สั่นเมื่อเดินทแยงหรือหยุด** — เดินทแยงใช้ทิศแกนที่ขยับมากกว่า, ระยะน้อยมากถือว่ายืน → เทสต์ `facingFrom` (Task 4)

**Interfaces:**
- Produces (`client/src/art/ninjaAtlas.ts`):
  - `TILESET_COLS = 28`, `TILESET_ROWS = 40`, `frameAt(col: number, row: number): number`
  - `GROUND: Record<"water" | "sand" | "grass" | "forestFloor", number>` — water = กลางบ่อ `frameAt(20, 8)`, sand = `frameAt(18, 8)`, grass = `frameAt(22, 11)`, forestFloor = `frameAt(23, 11)`
  - `SHORE: { n, s, w, e, nw, ne, sw, se: number }` — ชุดขอบบ่อ 3×3 ที่ col 19–21, row 7–9 (เช่น `n = frameAt(20, 7)`, `nw = frameAt(19, 7)`, `se = frameAt(21, 9)`)
  - `GROUND_DECOR: Record<"flower" | "tuft" | "pebble", number[]>` — frame ของของตกแต่งเตี้ย 16×16 (ผู้สร้างเลือกช่องจาก tileset ตามที่ดูเข้ากัน)
  - `TREE_RECTS: { x: number; y: number; w: number; h: number }[]` — สี่เหลี่ยมพิกเซลของต้นไม้ใหญ่ใน tileset (≥ 2 แบบ, กว้าง ≥ 32)
  - `SURVIVOR_IDS: readonly string[]` — 8 ไฟล์ตัวละครที่ดูเป็นคนธรรมดา/นักสำรวจ (ตัวเลือกแรก: `["14", "3", "4", "6", "8", "12", "13", "25"]` — ตรวจด้วยตาแล้วสลับได้, ห้ามชุดนินจา/ซามูไร/หุ่น/โครงกระดูก)
  - texture keys: `"ninja-tiles"` (spritesheet 16×16 ของ tileset), `"tree-<i>"` (frame ย่อยบน texture `"ninja-tiles-image"`), `"survivor-<id>"` (spritesheet 16×16)

### Task 4: ตัวละครเดินมีท่า 4 ทิศ

**Interfaces:**
- Consumes: `SURVIVOR_IDS`, texture `"survivor-<id>"` (Task 1); `PlayerSprites.update(pos)` เดิม
- Produces:
  - `type Facing = "down" | "up" | "left" | "right"`
  - `facingFrom(dx: number, dy: number, prev: Facing): { facing: Facing; moving: boolean }` — `moving = |dx| + |dy| > 0.05` (พิกเซลต่อเฟรม); ไม่ขยับ → คงทิศเดิม; ทแยง → แกนที่ |ค่า| มากกว่า, เท่ากันให้แนวนอนชนะ

  - ผู้เล่นใช้ไฟล์ `SURVIVOR_IDS[colorIndex % 8]`; ยืนนิ่ง = หยุด anim ที่เฟรมแถว 0 ของทิศปัจจุบัน; ลบชั้น `survivor-shirt` เดิมและ tint ออก
