- เซิร์ฟเวอร์เมินคำขอผิดเงียบๆ · ไม่มี native dependency ใหม่ · `server/data/` อยู่ใน .gitignore

## Review Focus
1. **วางกำแพงทับผู้เล่น/ทับของ/นอกระยะ/บนน้ำ** → ไม่วาง ไม่เสียของ (เทสต์ Task 2)
2. **ไฟล์บันทึกเสีย หรือรหัสแปลก (`../x`, ยาวมาก)** → ไม่ล่ม ไม่เขียนนอกโฟลเดอร์ (เทสต์ Task 3)
3. **token เดียวกันเข้าสองแท็บ** → คนที่สองถูกปฏิเสธ ไม่ duplicate ตัวละคร (เทสต์ Task 3)
4. **ตายแล้วถุงของหาย/เก็บซ้ำได้สองคน** → เก็บได้ครั้งเดียว (เทสต์ Task 2)
5. **ฟื้นที่ที่นอนที่ถูกรื้อไปแล้ว** → กลับไปจุดเกิดปกติ (เทสต์ Task 2)
