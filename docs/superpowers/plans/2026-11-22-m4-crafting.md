# ขั้นที่ 4 คราฟต์ — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** ทำขวาน/ค้อน/กองไฟจากของที่เก็บได้, วางกองไฟ, ย่างผลไม้, เครื่องมือเพิ่มผลผลิต

**Architecture:** สูตรและตัวเลขใน `balance.json` · กติกา pure ใน `shared/src/rules/crafting.ts` ใช้ทั้งสองฝั่ง · เซิร์ฟเวอร์เพิ่ม `structures` ใน state และข้อความ `craft/place/cook` · client เพิ่มหน้าคราฟต์ (HTML), กระเป๋าแบบยืดได้, วาดกองไฟ

**Spec:** `docs/superpowers/specs/2026-11-22-m4-crafting-design.md`

## Global Constraints
- ตัวเลข/สูตรอ่านจาก `balance.json` เท่านั้น · เครื่องมือ 1 ชิ้นต่อชนิด · กองไฟสูงสุด 30 ต่อโลก
- เซิร์ฟเวอร์เมินคำขอผิดเงียบๆ · ข้อความไทย · ห้าม innerHTML · เทสต์เดิมต้องผ่าน

## Review Focus
1. **คราฟต์ตอนของไม่พอ / recipe ปลอม / ทำเครื่องมือซ้ำ** → ไม่ได้ของ ไม่เสียของ (เทสต์ห้อง Task 2)
2. **วางกองไฟบนน้ำ/ทับต้นไม้/ทับกองไฟอื่น/เกินจำนวน** → ไม่วาง ไม่เสียกองไฟ (เทสต์ห้อง Task 2)
3. **ย่างโดยไม่อยู่ใกล้กองไฟ / ไม่มีผลไม้** → ไม่เกิดอะไร (เทสต์ห้อง Task 2)
4. **ผลผลิตจากเครื่องมือเกิน stack 99** → ตัดที่ 99 (เทสต์ Task 1)
5. **หน้าคราฟต์เปิดค้างตอนหลุด/กลับเมนู** → ปิดเมื่อออกจากฉาก (ตรวจในเบราว์เซอร์ Task 4)
