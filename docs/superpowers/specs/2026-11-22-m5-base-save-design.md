# เอกสารออกแบบ: ขั้นที่ 5 — สร้างฐาน + บันทึกโลก

วันที่: 2026-11-22 · โบ๊ทให้ทำจนครบทุกขั้นโดยไม่ต้องขออนุมัติ — ทุกข้อเป็นการตัดสินใจของ Claude (แก้ได้)

## เป้าหมาย
สร้างฐานได้ และ **โลกไม่หาย**: ปิดเซิร์ฟเวอร์/ทุกคนออกแล้วกลับมา ฐาน ทรัพยากร ตัวละคร และกระเป๋ายังอยู่ (สเปกหลัก §5.3, §5.5, §5.7)

**ไม่ทำในขั้นนี้:** กล่องเก็บของ (ต้องมีหน้าจอย้ายของ — เลื่อนไปขั้นที่ 7) · ฐานข้อมูลจริง (ใช้ไฟล์ JSON ก่อน)

## การตัดสินใจ
1. **สิ่งก่อสร้างใหม่** (คราฟต์ได้จากหน้า 🔨, สูตรใน `balance.json`)
   | ของ | ชื่อ | สูตร | ชน | ความสามารถ |
   |---|---|---|---|---|
   | wall | กำแพงไม้ | ไม้ 2 | ✔ | กั้นทาง |
   | door | ประตูไม้ | ไม้ 3 เส้นใย 1 | ✘ | เดินผ่านได้ (ทุกคน) |
   | bed | ที่นอน | ไม้ 3 เส้นใย 4 | ✘ | ตายแล้วฟื้นที่ที่นอนของตัวเอง (คนละ 1 ที่ วางใหม่ = ย้าย) |
   กองไฟเดิมยังอยู่
2. **วาง:** ข้อความ `place {item, tx, ty}` — วางที่ช่องเป้าหมาย (ไม่ใช่ที่ยืน) ต้องอยู่ในระยะเอื้อม, เป็นบก, ไม่มีของตกแต่ง/สิ่งก่อสร้าง/ผู้เล่นทับ · กองไฟยังห้ามติดกองไฟอื่น (กำแพงต่อกันได้) · สูงสุด 400 ชิ้นต่อโลก · client เลือกช่องหน้าตัวละคร (ตามทิศที่หัน)
3. **รื้อ:** ข้อความ `demolish {key}` — ใครก็รื้อได้ (เล่นร่วมกัน) ได้ของคืนเต็ม · กดค้างปุ่มรื้อ (โหมดก่อสร้าง)
4. **บันทึกโลก**
   - `WorldStore` (interface) + `JsonFileStore` เก็บที่ `server/data/worlds/<รหัส>.json` (ตั้งที่อื่นได้ด้วย `DATA_DIR`) — ไม่ใช้ SQLite เพราะต้องคอมไพล์ native บน Windows
   - บันทึกทุก 30 วินาที และตอนห้องปิด
   - **รหัสโลกถาวร** 6 ตัวอักษร (ตัด 0/O/1/I ที่สับสน) = `roomId` · เข้าโลกด้วย `joinOrCreate("world", {code})` + `filterBy(["code"])`: ห้องเปิดอยู่ → เข้าเลย, ปิดไปแล้วแต่มีไฟล์ → เปิดใหม่จากไฟล์, ไม่มีทั้งคู่ → "ไม่พบโลกนี้"
5. **กลับมาเป็นตัวเดิม:** browser สร้าง token สุ่ม เก็บใน localStorage ส่งตอนเข้า · เซิร์ฟเวอร์จำตำแหน่ง ค่าสถานะ กระเป๋า ที่นอน ตาม token · token ซ้ำที่กำลังออนไลน์ → ปฏิเสธคนที่สอง
6. **ตายแล้วของตก:** ของทั้งหมดในกระเป๋ากลายเป็น "ถุง" ที่จุดตาย (`state.drops`) · ใครก็เก็บได้ด้วยปุ่มโต้ตอบ (ลำดับแรกสุด) · หายเองใน 15 นาที
7. **ภาพ:** กำแพง ประตู ที่นอน และถุงของ Claude วาดเอง (pixel art) ให้เข้ากับ tileset

## ความเสี่ยงที่ต้องกัน
- วางกำแพงล้อมตัวเอง/คนอื่น → ห้ามวางทับผู้เล่น (คนในฐานยังติดได้ แต่รื้อกำแพงได้เสมอ)
- ไฟล์บันทึกเสีย/อ่านไม่ได้ → ไม่ล่ม เริ่มโลกใหม่ไม่ได้ (แจ้ง "ไม่พบโลก") และเก็บไฟล์เสียไว้
- รหัสโลกในชื่อไฟล์ → ตรวจรูปแบบรหัสก่อนแตะไฟล์ (กัน path traversal)
