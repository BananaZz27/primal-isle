# ขั้นที่ 6ข — แอปบนหน้าจอโฮม (PWA) + ขึ้นออนไลน์ (ออกแบบ)

> วันที่ 2026-11-22 · ต่อจากขั้นที่ 6ก · โบ๊ทสั่ง "ทำให้ครบทุกขั้นตอน" — Claude ตัดสินใจเองทุกข้อ ยกเว้นการสมัครบริการ (ต้องใช้บัญชีของโบ๊ท)

## ทำไม / เป้าหมาย
ตอนนี้เล่นได้แค่ Wi-Fi เดียวกัน (เซิร์ฟเวอร์อยู่บนคอมโบ๊ท) เป้าหมายคือเพื่อนต่างบ้านเปิดลิงก์แล้วเล่นได้ทันที และเพิ่มเกมเป็นไอคอนบนหน้าจอโฮมมือถือได้เหมือนแอป

**เป้าหมาย:**
1. PWA: manifest + ไอคอน (ไดโนพิกเซล) + service worker เก็บไฟล์เกมไว้ในเครื่อง (เปิดครั้งต่อไปเร็ว) · เปิดจากไอคอน = เต็มจอแนวนอน
2. หน้าเว็บเกม (client) ขึ้น **GitHub Pages** ผ่าน GitHub Actions (ฟรี, https) — ที่อยู่ `https://bananazz27.github.io/primal-isle/`
3. เซิร์ฟเวอร์เกมพร้อมขึ้น **Render** (ง่ายสุด) หรือ **Oracle Cloud Always Free** (เปิดตลอด, เก็บเซฟถาวร) — มี `Dockerfile` ใช้ได้ทั้งคู่, `render.yaml` สำหรับ Render
4. คู่มือภาษาไทยทีละขั้น `docs/DEPLOY.md`: สมัคร → ใส่ค่า → กดปุ่ม → ทดสอบ

**ไม่ทำ:** ซื้อโดเมน, ระบบบัญชีผู้ใช้, แอปบน store
**ต่อต้าน:** เผย token/รหัสลับใน repo · หน้าเว็บเก่าค้างในเครื่องหลังอัปเดตเกม (service worker ต้องอัปเดตเอง) · โหมดดีบัก `/monitor` เปิดบนเซิร์ฟเวอร์จริง

## เลือกที่ตั้งเซิร์ฟเวอร์ (โบ๊ทเลือกตอนสมัคร — คู่มือมีทั้งสองทาง)
| | Render free | Oracle Always Free |
|---|---|---|
| สมัคร | อีเมล/GitHub ไม่ต้องใช้บัตร | ต้องใช้บัตร (ไม่ตัดเงิน) |
| เปิดตลอด | หลับเมื่อไม่มีคนใช้ 15 นาที (ปลุก ~1 นาที) | เปิดตลอด |
| เซฟโลก | **หายเมื่อเซิร์ฟเวอร์รีสตาร์ท/อัปเดต** (ไม่มีดิสก์ถาวร) | เก็บถาวร |
| ความยาก | กดไม่กี่ปุ่ม | ต้องตั้งเครื่อง Linux (คู่มือให้คำสั่งครบ) |
**Claude แนะนำ:** เริ่ม Render เพื่อลองกับเพื่อนก่อน ถ้าชอบค่อยย้ายไป Oracle

## การตั้งค่า
- client อ่าน `VITE_SERVER_URL` ตอน build ← ตัวแปร repo `SERVER_URL` (เช่น `wss://primal-isle.onrender.com`)
- workflow `pages.yml`: build client → deploy Pages · ทำงานเมื่อกดเอง หรือ push เข้า main เมื่อมีตัวแปร `SERVER_URL` แล้ว (ก่อนตั้งค่าจะไม่รัน จึงไม่มีกากบาทแดง)
- เซิร์ฟเวอร์: `NODE_ENV=production` (ปิด `/monitor`/playground), `PORT` จากโฮสต์, `DATA_DIR` ที่เก็บเซฟ, `/health` สำหรับตรวจ
- service worker: `vite-plugin-pwa` (MIT) แบบ `autoUpdate` — เวอร์ชันใหม่ถูกโหลดเองเมื่อเปิดเกมครั้งถัดไป ไม่แคชการต่อเซิร์ฟเวอร์ (websocket)

## Approaches
1. **GitHub Pages + Render/Oracle (เลือก)** — ฟรีทั้งคู่ ใช้บัญชี GitHub ที่มีอยู่ สองส่วนแยกกันอัปเดตได้อิสระ
2. ให้เซิร์ฟเวอร์เกมเสิร์ฟหน้าเว็บเองด้วย — ที่อยู่เดียว แต่ Render หลับ = หน้าเว็บก็หลับ (เปิดลิงก์แล้วรอนาน) และ service worker ซับซ้อนขึ้น
3. Colyseus Cloud — ง่ายที่สุดแต่เสียเงิน ขัดกับเป้า "ฟรี"
