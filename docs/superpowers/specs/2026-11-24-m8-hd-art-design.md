# ขั้นที่ 8: ภาพละเอียด 2 เท่า (32px) — เอกสารออกแบบ

> 2026-11-24 · โบ๊ทเลือก: "วาดใหม่ทั้งเกม 2 เท่า (32px)" (ไม่ผสม 16px กับ 32px)
> ทำคู่กับป้ายชื่อเป้า ✋ (เสร็จแล้ว merge แล้ว: `client/src/ui/targetLabel.ts`)

## เป้าหมาย
ภาพทุกอย่างในโลก (พื้น ต้นไม้ หิน พุ่มไม้ ตัวละคร ไดโน สิ่งก่อสร้าง กองไฟ กล่อง ไอคอน) มีรายละเอียด 32×32 ต่อช่อง
แทน 16×16 · ขนาดบนจอเท่าเดิม (1 ช่อง ≈ 48 CSS px) · คมบนจอความละเอียดสูง (แท็บเล็ต/มือถือ)

## สิ่งที่ไม่เปลี่ยน
- กติกาเกม/เซิร์ฟเวอร์: โลกยังนับ 16 หน่วยต่อช่อง (`TILE_SIZE`), ระยะเอื้อม, ความเร็ว, ไฟล์บันทึก — ไม่แตะ
  (= ไม่ต้อง deploy เซิร์ฟเวอร์ใหม่ ไม่ทำให้โลกที่เล่นอยู่หาย)
- UI ที่เป็น HTML (กระเป๋า แถบเลือด ปุ่ม) — ไอคอนในกระเป๋าเปลี่ยนเป็นภาพ 32px ใหม่

## ภาพมาจากไหน
asset pack ฟรี (CC0/CC-BY) ที่ละเอียด 32px และมีครบทั้งพื้น/คน/ไดโนแบบเข้ากันหาไม่ได้ และเซสชันดาวน์โหลดจากเว็บทั่วไปไม่ได้
→ **วาดเองด้วยโค้ด** แบบเดียวกับที่ทำอยู่ แต่ใช้ "ชุดเครื่องมือวาด" (`client/src/art/hd/`) แทนการพิมพ์ทีละพิกเซล:
- สีเป็น "ramp" ต่อวัสดุ (มืด → สว่าง 4–6 ขั้น) แสงมาจากซ้ายบนทุกภาพ → ทั้งเกมดูเป็นชุดเดียวกัน
- รูปทรงพื้นฐาน: วงรี/ทรงกลมลงเงา, หลายเหลี่ยม, เส้น · ลวดลายสุ่มแบบกำหนด seed (ใบไม้ ใบหญ้า เปลือกไม้) · เส้นขอบเลือกสี (selective outline)
- ผลลัพธ์เป็น RGBA ล้วน (ไม่แตะ Phaser) → เทสต์ขนาด/ความโปร่งใสได้ และสร้างภาพตัวอย่าง PNG นอกเกมได้
- Pixel-boy เดิมเลิกใช้ทั้งหมดเมื่อครบ (ลบออกจาก `CREDITS.md` ตอนนั้น)

## การแสดงผล
- texture 32 texel ต่อช่อง วาดที่ scale 0.5 (โลกยัง 16 หน่วยต่อช่อง)
- canvas ความละเอียดเท่าจอจริง (คูณ `devicePixelRatio`) แล้วเลือกซูมให้ 1 texel = จำนวนพิกเซลจอเป็นจำนวนเต็มเสมอ
  (เช่น DPR 2 → 3 พิกเซลจอ/texel พอดี) — ไม่งั้นเม็ดพิกเซลจะหนาไม่เท่ากัน
- ตัวหนังสือในโลก (ชื่อ ป้าย) ปรับ resolution ตาม DPR

## ลำดับงาน (แต่ละชุดตรวจในเบราว์เซอร์ก่อนไปต่อ)
0. **ชุดเครื่องมือ + ภาพตัวอย่าง** (หญ้า ต้นไม้ หิน พุ่มไม้ แร็พเตอร์) → ส่งให้โบ๊ทดูสไตล์ก่อน ← *รอบนี้*
1. ระบบแสดงผล 32px + DPR (ยังใช้ภาพเก่าที่ขยาย 2 เท่าไปก่อน เกมต้องดูเหมือนเดิม)
2. พื้น: หญ้า พื้นป่า ทราย น้ำ + ขอบชายฝั่งทุกแบบ (16 แบบ)
3. ของบนแผนที่: ต้นไม้ 2 แบบ + ตอ, หิน, พุ่มไม้ (มีผล/ไม่มีผล), กอหญ้า, ดอกไม้
4. ตัวละคร 8 แบบ × 4 ทิศ × ท่าเดิน
5. ไดโน 4 ชนิด × 2 เฟรม
6. สิ่งก่อสร้าง กองไฟ (เฟรมไฟ) ถุงของ ลังเสบียง กล่องเก็บของ
7. ไอคอน 18 ชิ้น
8. ลบ Pixel-boy, อัปเดต CREDITS/README, review, merge

## ความเสี่ยง
- ขนาด texture ใหญ่ขึ้น 4 เท่า → วาดตอนเปิดเกม (BootScene) อาจช้าบนมือถือ: วัดเวลา ถ้าเกิน ~1 วิ ให้ cache เป็น PNG ตอน build
- ภาพวาดด้วยโค้ดอาจไม่สวยเท่าศิลปินจริง → ตัดสินจากภาพตัวอย่างขั้น 0 ก่อนลงแรงทั้งหมด
