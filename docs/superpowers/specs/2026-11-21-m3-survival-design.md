# เอกสารออกแบบ: ขั้นที่ 3 — เอาชีวิตรอด

วันที่: 2026-11-21 · โบ๊ทสั่งให้ทำต่อได้เลยโดยไม่ต้องขออนุมัติ — การตัดสินใจทั้งหมดในเอกสารนี้เป็นของ Claude (แก้ได้)

## เป้าหมาย
เกาะเริ่ม "มีอะไรให้ทำ": เก็บทรัพยากร, กระเป๋า, ค่าเลือด/หิว/น้ำ, กิน/ดื่ม — ตามสเปกหลัก §5.5 และขั้นที่ 3 ใน §5.9

**ไม่ทำในขั้นนี้:** คราฟต์ (ขั้นที่ 4) · ของตกที่จุดตาย (ต้องมีระบบของวางบนพื้น — ขั้นที่ 5) · บันทึกโลก (ขั้นที่ 5) · สัตว์ (ขั้นที่ 6)

## การตัดสินใจ
1. **ทรัพยากร = ของตกแต่งเดิม** (`generateDecor`) — id ของทรัพยากร = ลำดับใน list ที่ได้จาก seed (ทุกเครื่องตรงกัน)
   | ชนิด | ได้ | ตีกี่ครั้งหมด | งอกใหม่ | ชนได้ |
   |---|---|---|---|---|
   | ต้นไม้ | ไม้ (wood) | 3 | 120 วิ | ✔ |
   | หิน | หิน (stone) | 3 | 180 วิ | ✔ |
   | พุ่มไม้ (ใหม่) | ผลไม้ (berry) | 2 | 60 วิ | ✘ |
   | กอหญ้า | เส้นใย (fiber) | 1 | 60 วิ | ✘ |
   ดอกไม้เป็นของตกแต่งเฉยๆ · ต้นไม้ที่หมดแล้วเหลือตอ (เดินผ่านได้) · ถ้ามีผู้เล่นยืนทับตอนจะงอก ให้รอก่อน (ไม่ให้ติดในต้นไม้)
2. **ค่าสถานะ** 0–100: หิวลดหมดใน 10 นาที, น้ำลดหมดใน 7 นาที; หิวหรือน้ำเป็น 0 → เลือดลด 1/วิ; หิวและน้ำ > 50 → เลือดฟื้น 0.5/วิ
   กินผลไม้ +20 หิว · ดื่มที่ริมน้ำ +25 น้ำ · เลือด 0 → ฟื้นที่จุดเกิด ค่าเต็ม 100 (ของในกระเป๋ายังอยู่ — ของตกที่จุดตายรอขั้นที่ 5)
3. **ตัวเลขสมดุลอยู่ในไฟล์ข้อมูล** `shared/src/data/balance.json` (สเปกหลัก §5.2 data-driven)
4. **เซิร์ฟเวอร์ตัดสินทุกอย่าง**: ข้อความ `gather {node}`, `eat {item}`, `drink {}` — ตรวจระยะ (≤ 24px ≈ 1.5 ช่อง จากกลางตัวถึงกลางช่อง), คูลดาวน์ตี 350ms, ของพอไหม, ติดน้ำไหม
5. **กระเป๋า** = จำนวนต่อชนิดของ (สูงสุด 99 ต่อชนิด) ยังไม่มีช่องจำกัด (มีของ 4 ชนิด)
6. **การชน**: ต้นไม้และหินที่ยังไม่หมดเป็นของแข็ง — `stepPlayer` รับฟังก์ชัน `solid(tx,ty)` เพิ่ม (ใช้ทั้ง server และ client prediction)
7. **การควบคุม**: Space/E (คอม) หรือปุ่ม ✋ มุมขวาล่าง (มือถือ) = โต้ตอบกับสิ่งที่ใกล้ที่สุดในระยะ (ทรัพยากร ไม่งั้นน้ำ) · แตะ/คลิกผลไม้ในกระเป๋า = กิน
8. **หน้าจอ**: แถบ ❤️/🍖/💧 มุมซ้ายบน (HTML), กระเป๋าตรงกลางล่าง, ตัวเลข "+1 ไม้" ลอยขึ้นตอนเก็บ, ทรัพยากรสั่นตอนโดนตี, ข้อความตอนสลบ
9. **ภาพ**: พุ่มไม้ = tileset (13,9); ไอคอนของ: ไม้ = ตอ (9,8), หิน = (0,7), ผลไม้ = (1,9), เส้นใย = `items/food/tea-leaf.png`; ไอคอนค่าสถานะ = `items/heart.png`, `items/food/beaf.png`, `items/water-pot.png` (CC0 Pixel-boy)

## ความเสี่ยงที่ต้องกันไว้
- client ทำนายการเดินด้วยสถานะต้นไม้ที่ช้ากว่าเซิร์ฟเวอร์เล็กน้อย → reconcile แก้เอง (ยอมรับได้)
- ส่ง `gather` รัวๆ / id มั่ว / ไกลเกิน → เซิร์ฟเวอร์ปฏิเสธเงียบๆ
- ตายระหว่างเน็ตสะดุด → ค่าในเซิร์ฟเวอร์ถูกเสมอ
